# Basics

**Rounding Fractions:** Round down, even if the fraction is one-half or larger. _Exception:_ damage rolls and hit points have a minimum of 1.

## Ability Modifiers

**Standard Modifier:** Apply to related skill checks and saving throws. Unless otherwise specified, "ability modifier" refers to the standard modifier.

| Ability Score | Modifier |
| :-----------: | :------: |
|      2–3      |    -3    |
|      4–5      |    -2    |
|      6–7      |    -1    |
|     8–13      |    0     |
|     14–15     |    +1    |
|     16–17     |    +2    |
|     18–19     |    +3    |

**Full Modifier:** Calculated as `ability score – 10`. Use this modifier instead for ability checks.

| Ability Score | Full Modifier |
| :-----------: | :-----------: |
|       3       |      -7       |
|       4       |      -6       |
|       5       |      -5       |
|      ...      |      ...      |
|      16       |      +6       |
|      17       |      +7       |
|      18       |      +8       |

**Note:** Both sequences continue in each direction: 1 standard modifier point per 2 ability score points and 1 full modifier point per ability score point.

## Core Rolls

**Skill Check:** d20 + skill bonus + ability modifier

**Saving Throw:** d20 + save bonus + ability modifier

**Ability Check:** d20 + full ability modifier

A roll succeeds if it meets or exceeds the target number: Armor Class (AC) for weapon skill checks, or Difficulty Class (DC) for saving throws and other skill or ability checks.

## Determining Difficulty Class

**Saving Throw vs. Special Attack:** `12 + ½ the monster’s Hit Dice (HD)`

- E.g. a Basilisk's petrifying gaze (HD 6) has a DC of 12 + 3 = 15.

**Saving Throw vs. Spell:** `12 + spell level + spellcasting ability modifier`

- E.g. a _confusion_ spell (level 4) cast by a Mage with Intelligence 16 (+2) has a DC of 12 + 4 + 2 = 18.

**Skill or Ability Check:** Determine the DC based on the task's difficulty, or refer to the Dungeon Level column for the typical DC at that level. If unsure, use a DC of 15.

| Task Difficulty | Dungeon Level | DC  |
| --------------- | :-----------: | :-: |
| Very Easy       |       0       |  9  |
| Easy            |      1–3      | 12  |
| Medium          |      4–7      | 15  |
| Hard            |     8–12      | 18  |
| Very Hard       |      13+      | 21  |
