# Basics

**Rounding Fractions:** Round down, even if the fraction is one-half or more. _Exception:_ damage and hit point rolls have a minimum of 1.

**Units of Measurement:** Distances are in feet (ft) or yards (yd). Weight is in pounds (lb).

## Ability Modifiers

**Standard Modifier:** Add to related skill checks and saving throws. If unspecified, assume the standard modifier.

| Ability Score | Standard Mod. |
| :-----------: | :-----------: |
|       3       |      -3       |
|      4–5      |      -2       |
|      6–7      |      -1       |
|     8–13      |       0       |
|     14–15     |      +1       |
|     16–17     |      +2       |
|      18       |      +3       |

**Ability Check Modifier:** Calculated as `ability score – 10`. Use this modifier instead for ability checks.

| Ability Score | Ability Check Mod. |
| :-----------: | :----------------: |
|       3       |         -7         |
|       4       |         -6         |
|       5       |         -5         |
|      ...      |        ...         |
|      16       |         +6         |
|      17       |         +7         |
|      18       |         +8         |

**Note:** Both sequences continue in each direction: 1 standard mod. per 2 ability score points, and 1 ability check mod. for every ability score point.

## Core Rolls

**Skill Check:** `d20 + skill bonus + ability mod.`

**Saving Throw:** `d20 + save bonus + ability mod.`

**Ability Check:** `d20 + ability check mod.`

A roll succeeds if it meets or exceeds the target number:

- Armor Class (AC) for weapon skill checks
- Difficulty Class (DC) for saving throws and other checks

## Determining Difficulty Class

**Saving Throw vs. Special Attack:** `12 + ½ the monster’s Hit Dice (HD)`

- E.g. a Basilisk's petrifying gaze (HD 6) has a DC of 12 + 3 = 15.

**Saving Throw vs. Spell:** `12 + spell level + spellcasting ability mod.`

- E.g. a _confusion_ spell (level 4) cast by a Mage with Intelligence 16 (+2) has a DC of 12 + 4 + 2 = 18.

**Skill or Ability Check:** Determine the DC based on the task's difficulty, or refer to the Dungeon Level column for the typical DC at that level. If unsure, use a DC of 15.

| Task Difficulty | Dungeon Level | DC  |
| --------------- | :-----------: | :-: |
| Very Easy       |       0       |  9  |
| Easy            |      1–3      | 12  |
| Medium          |      4–7      | 15  |
| Hard            |     8–12      | 18  |
| Very Hard       |      13+      | 21  |
